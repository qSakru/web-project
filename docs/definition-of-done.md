# Definition of Done

**Definition of Done** on Scrum-tiimin yhteinen kuvaus siitä, milloin työ täyttää tuotteelta vaadittavat laatuvaatimukset ja voidaan laskea osaksi Incrementiä.

## Product Backlog -kohde on valmis, kun:

- [x] Koodi on toteutettu
- [x] Koodi on katselmoitu (code review)
- [x] Yksikkötestit on tehty ja ne menevät läpi
- [x] Tarvittavat integraatiotestit on tehty
- [x] Käyttöliittymä toimii suunnitellusti
- [x] Dokumentaatio on päivitetty
- [x] Koodi on versionhallinnassa
- [x] Kaikki automaattiset testit menevät läpi
